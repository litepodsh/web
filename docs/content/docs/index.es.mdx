Despliega aplicaciones y bases de datos en tu propio servidor sin convertir cada lanzamiento en un proyecto de infraestructura.

## ¿Qué es Litepod?

Litepod es un control plane ligero para desplegar aplicaciones y bases de datos en un servidor que alquilas y controlas.

Te ofrece una forma más sencilla de trabajar con tu infraestructura sin tener que construir y mantener una plataforma desde cero.

## ¿Por qué Litepod?

Mantienes el control de dónde corren tus servicios mientras reduces el trabajo repetitivo de despliegue.

Litepod está diseñado para ser:

- **Ligero:** usa un control plane enfocado en lugar de un stack de plataforma grande.
- **Fácil:** pasa del servidor a la aplicación funcionando mediante pocas acciones claras.
- **Rápido:** acorta el camino entre tener código y tener un servicio desplegado.

## Antes de empezar

Necesitas un servidor que controles y una aplicación o base de datos que quieras ejecutar en él. Litepod funciona como la capa entre tu infraestructura y los servicios que despliegas.

Tú sigues siendo responsable del servidor, los datos, el control de acceso, los backups y la monitorización. Litepod se enfoca en hacer el despliegue más sencillo y repetible.
