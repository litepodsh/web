Usa Litepod para ejecutar bases de datos en infraestructura que alquilas y controlas.

## Qué necesitas

- Un servidor con recursos adecuados para tu base de datos.
- La configuración de base de datos que necesita tu aplicación.
- Un plan para accesos, almacenamiento, backups y monitorización.

## Flujo de despliegue

1. Selecciona el servidor para la base de datos.
2. Configura el servicio de base de datos.
3. Define los datos de conexión que necesita tu aplicación.
4. Inicia el despliegue.
5. Comprueba la conexión y mantén el servicio operativo.

Ejecutar una base de datos en tu propio servidor te da control sobre su entorno, pero también significa que eres responsable de operar el servicio de datos de forma segura.

## Lista operativa

- Restringe el acceso de la base de datos a los servicios y personas que lo necesitan.
- Protege las credenciales y rótalas cuando sea necesario.
- Prueba los backups antes de depender de ellos.
- Monitoriza el almacenamiento, la memoria y la salud del servicio.
- Mantén actualizadas la versión de la base de datos y la seguridad del servidor.
