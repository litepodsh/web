Use Litepod to run databases on infrastructure you rent and control.

## What you need

- A server with resources appropriate for your database.
- The database configuration required by your application.
- A plan for access, storage, backups, and monitoring.

## Deployment workflow

1. Select the server for the database.
2. Configure the database service.
3. Set the connection details your application needs.
4. Start the deployment.
5. Verify connectivity and keep the service maintained.

Running a database on your own server gives you control over its environment, but it also means you are responsible for operating the data service safely.

## Operational checklist

- Restrict database access to the services and people that need it.
- Protect credentials and rotate them when necessary.
- Test backups before relying on them.
- Monitor storage, memory, and service health.
- Keep the database version and server security updates current.

Read [Applications](/en/applications) to see how application services fit into the same environment.
