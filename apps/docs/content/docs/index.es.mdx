Despliega aplicaciones y bases de datos en infraestructura que controlas sin convertir cada lanzamiento en un proyecto de operaciones.

## ¿Qué es Litepod?

Litepod es un control plane ligero para desplegar aplicaciones y bases de datos en un servidor que alquilas y controlas. Te ofrece una forma práctica de operar tu propia infraestructura sin tener que construir y mantener una plataforma desde cero.

## ¿Por qué Litepod?

Mantienes el control de dónde corren tus servicios mientras reduces el trabajo repetitivo de despliegue.

- **Tu infraestructura:** las aplicaciones y los datos permanecen en los servidores que eliges.
- **Menos configuración al desplegar:** usa repositorios Git, Dockerfiles, archivos Compose o cargas estáticas.
- **Un control plane enfocado:** administra aplicaciones, bases de datos, dominios y backups sin un stack de plataforma grande.
- **Recuperación intencional:** protege la configuración de Litepod con backups S3 y un flujo de restauración documentado.

## Lo que necesitas

Necesitas un servidor Linux que controles, una IP pública y una aplicación o base de datos para ejecutar. Litepod corre con 1 CPU y 800 MB de RAM; para usarlo de forma regular y alojar aplicaciones, empieza con 2 CPU y 4 GiB de RAM, y dimensiona el servidor según los workloads que alojes. Litepod instala y administra Podman; el servidor, los datos, los accesos, los backups y la monitorización siguen bajo tu responsabilidad.
