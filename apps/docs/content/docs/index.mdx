Deploy applications and databases on your own server without turning every release into an infrastructure project.

## What is Litepod?

Litepod is a lightweight control plane for deploying applications and databases on a server you rent and control.

It gives you a simpler way to work with your infrastructure without requiring you to build and maintain a platform from scratch.

## Why Litepod?

You keep control of where your services run while reducing repetitive deployment work.

Litepod is designed to be:

- **Lightweight:** use a focused control plane instead of a large platform stack.
- **Easy:** move from server to running application through a small number of clear actions.
- **Fast:** shorten the path between having code and having a deployed service.

## Before you start

You need a server you control and an application or database you want to run on it. Litepod works as the layer between your infrastructure and the services you deploy.

You remain responsible for the server, data, access control, backups, and monitoring. Litepod focuses on making deployment easier and more repeatable.
