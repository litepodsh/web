Deploy applications and databases on infrastructure you control without turning every release into an operations project.

## What is Litepod?

Litepod is a lightweight control plane for deploying applications and databases on a server you rent and control. It gives you a practical way to run your own infrastructure without building and maintaining a platform from scratch.

## Why Litepod?

You keep control of where your services run while removing repetitive deployment work.

- **Own your infrastructure:** applications and data stay on servers you choose.
- **Deploy with less setup:** use Git repositories, Dockerfiles, Compose files, or static uploads.
- **Keep the control plane focused:** manage applications, databases, domains, and backups without a large platform stack.
- **Recover deliberately:** protect Litepod's configuration with S3 backups and a documented restore flow.

## What you need

You need a Linux server you control, a public IP address, and an application or database to run. Litepod itself runs on 1 CPU and 800 MB RAM; for regular use and hosting applications, start with 2 CPU and 4 GiB RAM, then size the server for the workloads you host. Litepod installs and manages Podman; the server, data, access control, backups, and monitoring remain yours to operate.
