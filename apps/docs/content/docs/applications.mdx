Use Litepod to deploy application services on a server you rent and control.

## What you need

- A server with enough resources for your application.
- Your application source and its required configuration.
- Access to the external services your application depends on.

## Deployment workflow

1. Select the server where the application should run.
2. Add the application's configuration.
3. Review the service settings.
4. Start the deployment.
5. Check the running service and update it when your code changes.

Litepod keeps the workflow focused so you can spend less time repeating server setup for each application.

## Domains and HTTPS

Caddy can route requests to your application and obtain SSL certificates from Let's Encrypt for configured domains. Your domain DNS must point to the server, and the server must be reachable for certificate issuance and HTTPS traffic.

### Custom certificates

To use your own certificate (Sectigo, DigiCert, GoDaddy, a Cloudflare Origin certificate, or an internal CA) instead of Let's Encrypt:

1. As a system administrator, open **Settings → Certificates** and choose **Add certificate**. Paste the certificate with its intermediate chain (PEM) and the matching unencrypted private key (PEM). Litepod checks that the key matches, the dates are valid and the certificate has DNS subject alternative names. The private key is stored encrypted.
2. In the application's domain, set **Certificate provider** to **Custom certificate** and select the saved certificate. Its names must cover the domain; a wildcard such as `*.example.com` covers `app.example.com`.
3. For the control panel domain, choose the same option in the **System** page.

One certificate can be reused by several domains. When you replace it in **Settings → Certificates**, every domain using it is updated. Custom certificates do not renew automatically: replace them before they expire.

**Cloudflare Origin certificates** are trusted only by Cloudflare, so keep the domain proxied (orange cloud) and set SSL/TLS to **Full (strict)**. The **Test** button will report that the chain is not trusted by the server; that is expected.

## Your responsibility

Application behavior, secrets, access control, domains, and application-level monitoring still need to be configured for your environment. Litepod provides the deployment layer; it does not replace application operations.
