title: Cómo funciona
description: Entiende cómo Litepod simplifica los despliegues en tu propio servidor.
---

Litepod se ejecuta en tu servidor y te ofrece un control plane enfocado para desplegar aplicaciones y bases de datos sin construir una plataforma desde cero. Caddy gestiona el reverse proxy y puede obtener certificados SSL de Let's Encrypt para tus dominios.

## El flujo de despliegue

1. **Conecta tu servidor.** Usa infraestructura que alquilas y controlas.
2. **Elige un servicio.** Selecciona la aplicación o base de datos que quieres ejecutar.
3. **Proporciona la configuración.** Añade los ajustes que el servicio necesita para iniciar correctamente.
4. **Despliega.** Inicia el despliegue desde la interfaz de Litepod.
5. **Enruta el tráfico de forma segura.** Caddy funciona como reverse proxy y puede obtener certificados SSL mediante Let's Encrypt.
6. **Gestiona desde un solo lugar.** Mantén visible y repetible el trabajo de despliegue.

## Qué sigue bajo tu control

Litepod simplifica el flujo de despliegue. Tú sigues controlando el servidor, la red, los datos, los accesos y las políticas operativas de tus servicios.

Ese equilibrio te da una experiencia ligera sin renunciar a la propiedad de tu infraestructura.
